# NAVI scripts

| Path | Status | What it does |
|---|---|---|
| `jobs/jobs.py`, `jobs/prompts/` | Working | Per-job models: planning, explore, writing, checks and batch_qa each run as a headless Claude Code subagent on the model and effort in `config/defaults.json` (`jobs`), by full ID. Falls back when a model is unavailable (with a warning in the batch report; never to Fable when nobody is watching), warns about claude-opus-4-6 after 2027-01-15, and logs model, effort, time and tokens per run. `jobs.py show`, `run <job>`, `ping`. |
| `explore/digest.py` | Working | A short readable list of an explore run (each button, link and field with its name and where it sits, in the position checker's own words) for the model jobs, instead of the full `explore.json`. |
| `jobs/test_jobs.py` | Working | The check for all of the above with a stand-in `claude` (nothing spent); `--live` asks each real model for one word. |
| `batch/blind.py`, `batch/test_blind.py` | Working | Blind A/B/C tests inside real batches: the outline planned once per arm and picked unlabelled; for the first 5 videos one draft per arm, each voiced once, picked by ear with the arm hidden; the picked take ships; picks recorded in `$NAVI_DATA/blind-picks.jsonl` and revealed in the batch report once all are made. |
| `batch/runner.py`, `batch/test_runner.py` | Working | A started batch as its own macOS background job (LaunchAgent): outlives T3 Code, Claude Code and session timeouts, keeps the Mac awake itself while it works, starts again after a crash or a restart and carries on, pause and resume with "paused at video 7 of 30". `runner.py start|stop|resume|status <batch>`. |
| `batch/restart_check.py` | Working | The real-restart test the user does once before a first overnight batch: `start` runs a small practice batch (saved takes, no credits) as a background job; after restarting the Mac and logging in, `check` says whether it carried on. Steps in `docs/before-first-overnight-batch.md`. |
| `record/rehearse.py` | Working | Plays every action of a script once, quickly, in the recorder's own browser (login, guard and blur as in a take) before any credits are spent, and lists the steps that can't be done with what the page offers. Part of `batch.py write`. |
| `explore/memory.py` | Working | Remembers what was explored on a site (per login and view) so the next video's explorer only walks what is new. `list`, `forget <site>`. |
| `focus/load_check.py` | Working | Records the to-do clip alone, under a render, under word timing, and two and three at once, and compares every take (`compare_takes.py`): decides whether `render_while_recording` and `record_parallel` may be switched on. |
| `setup/check.py` | Working | Readiness check: Node, NAVI's Python, ffmpeg, recorder + Playwright + Chromium, local word timings (a spoken test phrase), the ElevenLabs key and credits left. Installs nothing, spends nothing. `python3 scripts/setup/check.py` |
| `setup/install.sh` | Working | Installs everything above inside the repo (`.venv/`, `recorder/agent-screenplay/`). Ask the user first. |
| `setup/store-key.sh` | Working | Stores the ElevenLabs key in the macOS Keychain; the key is typed hidden, never shown. |
| `audio/dsp.py` | Working (from the pilot) | Pure-Python audio toolkit: WAV I/O, filters, BS.1770 loudness, de-esser, compressor, limiter, pitch tracker (YIN). No dependencies. |
| `audio/finality.py` | Working (from the pilot) | Scores how "finished" a take's last sentence sounds (pitch near the floor, energy draining). Used to rank takes. |
| `audio/treat.py` | Working (from the pilot) | The gentle voice treatment chain and room tone. |
| `voice/generate.py` | Adapted, not yet run against the API | One continuous read per section on eleven_v3, 2 takes, finality ranking, edge shaping, treatment. Prints the credit estimate and stops unless run with `--yes`. |
| `research/measure_speech.py` | Working | Measures a voice track like a real narrator: pace and pitch variation per phrase, pauses, fillers, repeats, breaths, clicks. Used for the research in `reference/research/` and for scoring new takes. |
| `research/transcribe_verbatim.py` | Working | Verbatim transcript (CrisperWhisper 2.0, keeps uh/um/repeats) with word timings. Model is non-commercial-research only. |
| `timing/timing.py` | Working (Phase 2) | Word timings from the finished voice track, locally (faster-whisper, one section at a time with its script as a hint, so restarts keep their real timing). Pins each action to its cue word, tags it explain / click / hunt / wait, checks every cue is heard, waits sit at section boundaries and the screen never sits still over 5 s. Writes `timing.json`, `timing.md` and, with `--preview`, a watchable `timing-preview.mp4`. |
| `record/record.py` | Working (Phases 3 and 4) | Records the browser live to the voice with the patched recorder: each step starts at a set time so its click or first key lands on its word; real-time footage, never retimed; the voice is laid over afterwards. Re-records (locally) to calibrate cursor travel, scans the frames for privacy, has Recordly's renderer draw the video (`--style casual|recordly`, `--restyle` to redo the other style), then runs the join checks. Writes `recording.mp4`, `report.md` and `privacy.md`. |
| `privacy/privacy.py`, `privacy/blur.js`, `privacy/patterns.json` | Working (Phase 4) | The privacy tiers as patterns (one file for both sides). The in-page blur runs before the page paints, the live page check runs before the first take, and the frame scan reads every distinct frame with Apple's text recognition. Writes the Review list (`privacy.json`, `privacy.md`). |
| `privacy/ocr.swift` | Working | Apple Vision text recognition, compiled on first use to `.venv/bin/navi-ocr`. Built into macOS; nothing to install. |
| `privacy/test_privacy.py` | Working | The Phase 4 check on `examples/privacy-test/` (fake data). It reads the finished videos back and fails on any readable private value or any over-blurred public one. |
| `script/check_script.py` | Working (Phase 6) | Catches what `voice-rules.md` bans before any credits are spent: cheerful one-word lines, "…" hesitations, tags other than `[relaxed]`, more than one restart per section, cut-off words, fillers as their own sentence, likely still screens over 5 s, and broken structure (cue words missing, unclean captions). It also warns about rules that need judgement. The voice step refuses a script with errors. |
| `script/variety.py` | Working | Variety (Andy, 11 Nov 2026: every video sounded the same): measures how each section starts, fillers and their place, kinds of repair, hunts, endings, sentence shape and shared phrases, and fails a script that repeats itself, a recent video (`$NAVI_DATA/script-history.jsonl`, the last 12) or another script in its batch. Part of `check_script.py` (`--batch`, `--record`, `--no-history`). |
| `script/style.py` | Working | The style of the day: drawn before a script is written (opening, markers on and resting, fillers, repair kinds, sentences, who acts, gaps between sections), away from recent videos and the rest of the batch. `--write` saves it in the script. |
| `script/drafts.py` | Working | Draft three, keep the best: `styles` draws three far-apart styles for a video (from recent videos and the batch so far); `pick` scores the drafts on quality (checker errors rule one out) and difference from recent videos and batch neighbours, and keeps the best as `script.json`. |
| `script/scale_test.py` | Working | The scale test: a 30-lesson course (`examples/variety/course-30.json`) written lesson by lesson through `drafts.py`, scripts only, then `report`; `draws` runs the style draw alone over many simulated batches. |
| `script/test_drafts.py` | Working | The narrator card (habits may repeat at their rate, nothing else), draft picking, batch rules near and far, and the history staying outside the repo. |
| `script/test_variety.py` | Working | The four scripts that all sounded the same fail; the same four rewritten (`examples/variety/`) pass on their own, as a batch and after the old ones. |
| `script/positions.py` | Working | Part of the script checker: every position in a script ("top right", "at the bottom of the form") is checked against the explore data, on screen and in the panel the target sits in. |
| `script/show_script.py` | Working | The talking and caption versions side by side, with actions, length and the checker's findings, for approval. |
| `script/test_check.py` | Working | The Phase 6 check: every banned pattern in `examples/script-checker/bad-script.json` is caught, and rule-following lines aren't. |
| `render/export.py` | Working (Phase 5) | Makes the files the user gets, named after the demo title, in the folder they name (default `~/Movies/NAVI`, never inside this repo): the 1080p MP4, `.srt` (unless captions are off), a transcript and an optional 720p preview. Captions burned in, file only, or off; the corner label is off, or the user's text in a chosen corner. Changing these only re-renders, in about 5 to 10 s. |
| `render/captions.py` | Working | The clean caption text, timed to the words the voice actually says (anchored on meaningful words), as cues of at most 2 lines of 42 characters. |
| `render/redo.py` | Working | Redo only the sections marked in Review: new takes for just those sections (shows the credits and needs `--yes`), or `--other-take` (free). Every other section keeps its exact take. Then it redoes the timing and records the whole video again (free). |
| `render/caption_png.mjs` | Working | Draws captions and the corner label with the browser (Mona Sans, rounded boxes) as transparent pictures for the export. |
| `render/test_export.py` | Working | The Phase 5 check: all caption modes and corners, both caption looks, captions ending with their words, and the sped-up copy (length and pitch), read back from the video. |
| `app/server.py` | Working (Phase 7, engine side) | The local app server on this Mac only: serves `ui/` read-only, `GET /api/state` (real settings, key status, logins, demos, batches), `POST /api/action`. See `docs/app-api.md`. |
| `app/wait.py` | Working | "Wait for the app": blocks until the user does something in the app and prints it, so clicks reach Claude. |
| `app/store.py` | Working | The app's state: settings, demos, saved logins, the key's status (never the key), and "Your data" (look first, then confirm). |
| `batch/batch.py` | Working (Phase 7) | Batch mode. A list goes in, every script is approved in one list, and the videos are recorded one after another, pausing before any video the credits can't finish. Then a review queue, and export plus a list file. Never publishes. |
| `app/test_app.py`, `batch/test_batch.py` | Working | The Phase 7 engine checks. |
| `explore/explore.mjs` | Working | Explore a site before writing the script: always headless (no window, nothing comes to the front), with the seat's saved login (`--seat`), the action guard on (a block stops it, exit 3; `--learn` logs and blocks every change, `--log-writes` logs the ones it allows) and, in a real business, the privacy blur on the screenshots, at the recording's size. A screenshot plus every visible button, link and field after each step. `--headed` is refused. |
| `cleanup/test_products.mjs` | Working | Deletes the products NAVI created (names starting "NAVI test") in a business the user marked as a test (`$NAVI_DATA/test-businesses.json`); refuses any other business. record.py runs it before and after every take. `--dry-run` lists only. |
| `seats/seats.py`, `seats/seats.mjs` | Working | Seats: named saved logins per site (owner) and the businesses they open, from `$NAVI_DATA/seats.json` (example `config/seats.example.json`). `seats.py pick <site> "<job>"` picks the seat for a video from its words (`config/seats.json`); `seats.py list` lists them. A login saved before seats becomes the owner seat's. |
| `seats/check_logins.mjs` | Working | Checks every saved login live, headless, guard on: `working`, `needs login` (sent to a sign-in page, bounced with a `next=` back, or a password field) or `unreachable`; `--pages` also checks pages open with that login (the batch preflight). Writes `$NAVI_DATA/login-status.json`. |
| `seats/test_seats.py` | Working | The picker on real kinds of jobs, the login files and a script's seat, on a throwaway `$NAVI_DATA`. |
| `guard/guard.mjs` | Working | The action guard: Chrome's own request interception (CDP Fetch, set on the whole browser, so the cache stays on) in every browser NAVI opens. Blocks withdrawing, transfers, refunds, card payments, bank/payout/billing details, API keys, team/ownership and deleting (except NAVI's own test products in a test business, from the cleanup); in a real business also any change the job didn't ask for, and unknown changes. Rules per site in `config/guard/<site>.json`. |
| `guard/catalogue.mjs` | Working | Lists every GraphQL operation a site's own scripts can send (headless, guard in learn mode), to build or check a guard pack. |
| `guard/test_guard.mjs` | Working | whop's real operations against the pack (every category, every seat); `--live` also proves on whop that a blocked "Create product" never reaches the server. |
| `focus/focuswatch.swift` | Working | Logs every app that comes to the front and every window NAVI's browser shows; built to `.venv/bin/navi-focuswatch` on first use. Built into macOS; nothing to install. |
| `focus/test_focus.py` | Working | The "never take over the Mac" check (recording-rules.md rule 22): a real explore and recording with the watcher on; `--login` also checks the login window never jumps back in front. |
| `focus/compare_takes.py` | Working | Compares two recordings of the same clip: frame timing, repeated frames, page response, cursor, scheduler lateness, actions against their words. |
| `../ui/engine.js` | Working (Phase 7) | The app's side of the wiring: served by `app/server.py`, the app shows the engine's state (demos, scripts, credits, logins, settings, the recording in Review) and sends every click as an action. Opened as a file it keeps its sample data. |

The recorder (agent-screenplay plus NAVI's patch) is in `../recorder/`.

Requirements: run `scripts/setup/install.sh` once. NAVI's Python is `.venv/bin/python` (3.12) and its ffmpeg is `.venv/bin/ffmpeg`, linked from the recorder's ffmpeg-static; nothing is installed system-wide. Run engine scripts with `.venv/bin/python`. The ElevenLabs key is read from the macOS Keychain (service `navi-elevenlabs`) or the `NAVI_ELEVENLABS_KEY` environment variable, never from a file in the repo.
