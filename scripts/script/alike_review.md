A narrator makes many short screen-recorded demos and viewers binge them back to back. Below are the opening lines of the recent videos ("EARLIER"), then the opening line of a new video ("NEW"). Detection only, no quality scoring: does NEW sound alike to a listener to any EARLIER line? Alike means the same move or shape even in different words: the same structure (e.g. a description of the screen, then ", so" and the action; a reason, then where it happens, then ", and I'll…"), the same turn of phrase, the same kind of afterthought, the same rhythm. Sharing an on-screen name (a button, a page), the topic (both make a product) or the plain fact of saying where something is ("in the sidebar", "top right", "on the Products page") is not alike by itself: every opening on the same site does that. Only a shared build (the same order of clauses joined the same way), a shared turn of phrase or a shared rhythm makes two lines alike; "strong" needs one of those that a listener would catch.

Output only one JSON array, nothing else: one object per EARLIER line that NEW sounds like: {"earlier": <its number>, "strength": "strong" | "mild", "shared": "<what they share, quoting words>"}. "strong" means a binge-listener would notice; "mild" means only on close listening. If NEW sounds like none of them, output [].
