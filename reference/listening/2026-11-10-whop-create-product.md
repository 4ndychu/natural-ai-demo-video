## Rules that came out of this video (Andy, the same day)

1. Start the cursor moving within the first second, so the opening is never still.
2. Captions must never cover what's being pointed at or clicked: move the caption to the top of the frame when the target is in the bottom part.
3. Never blur navigation labels like "Customers"; menu items stay visible.
4. Every position in a script is checked against the explored page, or described loosely ("at the bottom of the form"). This video said "bottom left" when it was the bottom right of the form.
5. In a test business only, NAVI may delete the products it created itself (names starting "NAVI test"), and cleans up after every recording try so the next take starts clean. Never delete anything in a real business.
