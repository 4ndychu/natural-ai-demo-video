## What it means (to act on)

- **Repetition across videos is a defect as serious as any single-video tell.** Same opening (a breath, then
  "Okay, so"), same step openers ("Right, so"), same filler placement, same kind of restart ("it's, it's"), same
  breathing: across a channel or a batch, that is what gives it away as made by a machine.
- **The rules themselves caused it.** Experiments that found one wording "best" (E3: "Okay. So now," / "Right,
  so,"; E1: a filler just before the name of the thing; "one restart per section") were written as recipes, so every
  script followed the same recipe. A winning example is one good option, not the template.
- **Variety has to be designed and checked**, within a video and across videos (a batch, and everything made
  recently), the same way single-video tells are.
- Andy asked for Fable 5.2 to be used on the fix.
